Ecuaciones bicuadradas

4º ESO · Matemáticas B · IES San José (Badajoz) · Cristina Ramos García

¿Qué es una ecuación bicuadrada?

Es una ecuación de 4.º grado sin términos de grado impar: solo tiene x^4, x^2 y número.

ax^4 + bx^2 + c = 0
donde a ≠ 0
✓
x^4 - 5x^2 + 4 = 0  es bicuadrada (completa).
✓
2x^4 - 32 = 0  también: le falta el término en x^2 (b = 0).
✓
x^4 - 25x^2 = 0  también: le falta el número (c = 0).
✗
x^4 + x^3 - 2 = 0  no lo es: tiene x^3.
✗
x^4 - 3x + 1 = 0  no lo es: tiene x.

Cómo se resuelve: 3 pasos

1
Cambio de variable. Llamamos x^2 = z, y entonces x^4 = z^2. La ecuación se convierte en una de segundo grado:
az^2 + bz + c = 0
2
Resolvemos la ecuación en z con la fórmula de siempre:
z = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}
3
Deshacemos el cambio. Como x^2 = z, de cada valor de z sacamos
x = \pm\sqrt{z}
Las soluciones son las x, no las z.
La ecuación en z se resuelve exactamente igual que una de segundo grado. Lo único nuevo es el último paso: hacer la raíz y poner el \pm.

Ejemplo resuelto (así se escribe en el examen)

Es el ejemplo del libro: resolver x^4 - 13x^2 + 36 = 0.

x^4 - 13x^2 + 36 = 0 \quad\xrightarrow{\;x^2 \,=\, z\;}\quad z^2 - 13z + 36 = 0
z = \dfrac{13 \pm \sqrt{169 - 144}}{2} = \dfrac{13 \pm 5}{2}\;\left\{\begin{array}{l} z = 9 \;\rightarrow\; x = \pm 3 \\[6pt] z = 4 \;\rightarrow\; x = \pm 2 \end{array}\right.
\text{Soluciones: } \; x_1 = 3, \quad x_2 = -3, \quad x_3 = 2, \quad x_4 = -2

En el examen, que no falte

  • El cambio x^2 = z escrito y la ecuación en z.
  • La fórmula con los números sustituidos, no solo el resultado.
  • Los dos valores de z y, de cada uno, sus valores de x.
  • Al final, la frase «Soluciones: x_1 = \dots» con todas.
  • Si sobra tiempo, comprobar una solución sustituyendo en la ecuación del principio.

¿Cuántas soluciones salen?

Depende del signo de cada valor de z:

z positiva
x = \pm\sqrt{z}
2 soluciones
z = 16 \rightarrow x = \pm 4
z igual a cero
x = 0
1 solución
x^2 = 0 \rightarrow x = 0
z negativa
x^2 = -4
Ninguna: ningún número al cuadrado da negativo

En total, una bicuadrada tiene como máximo 4 soluciones (puede tener 4, 3, 2, 1 o ninguna) y salen por parejas de opuestos: 3 y -3. Si te sale 3 sin su -3, algo has hecho mal.

Y si \Delta = b^2 - 4ac < 0, no hay valores de z, así que la bicuadrada no tiene solución.

Bicuadradas incompletas

Falta el término en x^2  (b = 0): se despeja

x^4 - 16 = 0 \;\Rightarrow\; z^2 = 16 \;\Rightarrow\; z = \pm 4 \;\left\{\begin{array}{l} z = 4 \;\rightarrow\; x = \pm 2 \\[6pt] z = -4 \;\rightarrow\; \text{no da solución} \end{array}\right.

Falta el número  (c = 0): factor común

x^4 - 25x^2 = 0 \;\Rightarrow\; x^2\,(x^2 - 25) = 0 \;\left\{\begin{array}{l} x^2 = 0 \;\rightarrow\; x = 0 \\[6pt] x^2 = 25 \;\rightarrow\; x = \pm 5 \end{array}\right.
No dividas entre x^2: perderías la solución x = 0.

Errores que más se repiten

1
Dar los valores de z como soluciones finales. Falta deshacer el cambio.
2
Olvidar el \pm: si x^2 = 9, entonces x = 3 y x = -3.
3
Hacer la raíz de una z negativa. Esa z se descarta.
4
Equivocarse con -b: si b = -13, entonces -b = 13.
5
No igualar a 0 antes de empezar: primero se pasa todo al primer miembro.
